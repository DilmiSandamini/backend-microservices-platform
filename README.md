## Project Description
This repository serves as the core platform layer for the Flavoriz microservices architecture. It includes essential Spring Cloud components such as the Config Server, Eureka Service Registry, and API Gateway to manage service discovery, routing, and centralized configuration

## Setup / Getting Started Instructions
1. Clone the **Source Code on GitHub** to your local machine.
2. Start the services in the following order: Config Server -> Eureka Registry -> API Gateway.
3. Run `mvn clean install` for each component to build the project.
4. Run the Spring Boot applications using your IDE or via the terminal.
